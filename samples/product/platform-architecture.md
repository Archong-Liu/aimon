## 模組說明

### 1. 資料擷取模組（Ingest）
- 支援批次檔案（CSV / Parquet）與串流（Kafka、Webhook）兩種進料方式。
- 標準連接器：SAP、Oracle EBS、Salesforce、S3、Azure Blob。
- 客戶自有系統走 Webhook + 我方 SDK；SDK 提供 Java / Python 兩種。
- 進料失敗有三次重試，超過即進入死信佇列並發告警。

### 2. 規則引擎（RuleEngine）
- 客戶可自訂驗證規則與告警門檻，規則以 DSL 撰寫，版本化管理。
- 規則變更需經客戶端管理者核可，有完整稽核軌跡。
- 高頻規則以記憶體快取加速，延遲 p95 < 200ms。

### 3. 報表模組（Reporting）
- 預設 12 張標準報表；客製報表由 PS 團隊以報表 SDK 開發。
- 支援排程寄送與 API 拉取。
- 匯出格式：XLSX、CSV、PDF。

## 部署形態

- **標準 SaaS 多租戶**：預設形態，共用叢集，租戶以 schema 隔離。
- **單租戶專屬叢集**：加價 40%，客戶要求資料落地或稽核隔離時採用。

## 整合限制

- 單筆進料檔案上限 2GB。
- 規則引擎不支援跨租戶查詢。
- 報表模組的即時查詢有 60 秒 timeout。
